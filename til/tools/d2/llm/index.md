# Генерация диаграмм из текста на языке D2: синтаксис, анимации и экспортирование

> Быстрый обзор декларативного языка D2 для создания архитектурных диаграмм из кода. Синтаксис, анимации, поддержка LaTeX и интеграция с проектами.

- **URL:** http://localhost:1314/til/tools/d2/
- **Date:** 2025-02-13

- **Tags:** диаграммы, визуализация, UML

---
Вы наверняка слышали или даже использовали [Mermaid](https://mermaid.js.org/), [PlantUML](https://plantuml.com/) или [Graphviz](https://graphviz.org/) для создания диаграмм. Но сегодня я хочу познакомить вас с D2 — ещё одним крутым скриптовым языком, который превращает текст в диаграммы! 🚀

D2 разработан компанией Terrastruct и предлагает множество фишек:
- 🎨 Поддержка тем, стилизаций и анимации
- 📝 Встроенная поддержка LaTeX и Markdown, переменных
- 💻 Подсветка кода для снипетов
- 🖼 Работа с внешними шрифтами и картинками
- 🔧 CLI и расширения для популярных IDE и многое другое

Если вы любите визуализировать данные или архитектуру, создавать uml диаграммы D2 — это must-try! 🚀

- 👉 Подробнее: https://d2lang.com/
- 👉 D2 Playground (https://play.d2lang.com/)
