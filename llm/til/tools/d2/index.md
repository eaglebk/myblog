# Генерация диаграмм из текста на языке D2: синтаксис, анимации и экспортирование

> Быстрый обзор декларативного языка D2 для создания архитектурных диаграмм из кода. Синтаксис, анимации, поддержка LaTeX и интеграция с проектами.

- **URL:** https://eagle2000.space/til/tools/d2/
- **Date:** 2025-02-13

- **Tags:** диаграммы, визуализация, UML

---

<p>Вы наверняка слышали или даже использовали <a href="https://mermaid.js.org/"  target="_blank" rel="noreferrer">Mermaid</a>, <a href="https://plantuml.com/"  target="_blank" rel="noreferrer">PlantUML</a> или <a href="https://graphviz.org/"  target="_blank" rel="noreferrer">Graphviz</a> для создания диаграмм. Но сегодня я хочу познакомить вас с D2 — ещё одним крутым скриптовым языком, который превращает текст в диаграммы! 🚀</p>
<p>D2 разработан компанией Terrastruct и предлагает множество фишек:</p>
<ul>
<li>🎨 Поддержка тем, стилизаций и анимации</li>
<li>📝 Встроенная поддержка LaTeX и Markdown, переменных</li>
<li>💻 Подсветка кода для снипетов</li>
<li>🖼 Работа с внешними шрифтами и картинками</li>
<li>🔧 CLI и расширения для популярных IDE и многое другое</li>
</ul>
<p>Если вы любите визуализировать данные или архитектуру, создавать uml диаграммы D2 — это must-try! 🚀</p>
