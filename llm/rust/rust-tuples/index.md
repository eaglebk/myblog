<p>В языке Rust есть несколько базовых композитных типов, позволяющих группировать значения. Один из наиболее простых и часто используемых — это <strong>кортеж (tuple)</strong>. Кортежи особенно удобны, когда нужно вернуть несколько значений из функции без создания отдельной структуры.</p>

<ul>
<li><strong>Кортеж</strong> — это композитный сложный тип данных фиксированной длины. После объявления его размер нельзя изменить.</li>
<li><strong>Синтаксические правила:</strong> Определяются путем перечисления типов через запятую внутри круглых скобок <code>()</code>.</li>
<li><strong>Состав типов:</strong> Перечисляемые в кортеже типы могут быть как абсолютно одинаковыми, так и полностью различаться.</li>
<li><strong>Вложенность:</strong> Допускается создание вложенных кортежей (кортеж как элемент другого кортежа).</li>
</ul>
<p>Давайте разберём различные варианты объявления кортежей, способов доступа к их элементам и работу с единичным типом на интерактивных слайдах ниже:</p>
### 💻 Работа с кортежами в Rust


#### Шаг 1


```rust
fn main() {
    // Пример кортежа с разными типами
    let t1: (u32, u8, f64) = (500, 1, 6.28);

    // Пример кортежа с одинаковыми типами
    let t2: (u32, u32, u32) = (10, 20, 30);

    // Пример вложенного кортежа
    let t3: (u32, (u64, u8), u32) = (100, (50, 2), 200);

    println!("t1: {:?}", t1);
    println!("t2: {:?}", t2);
    println!("t3: {:?}", t3);
}
```


**Объявление кортежей в Rust**
- Кортеж создается путем перечисления значений через запятую в круглых скобках `()`.
- Типы элементов могут полностью отличаться (`t1`) или быть одинаковыми (`t2`).
- Кортежи могут содержать другие кортежи в качестве элементов (`t3`), формируя вложенные структуры.


#### Шаг 2


```rust
fn main() {
    let x: (i32, f64, u8) = (500, 6.4, 1);

    // Доступ к элементам по порядковому номеру (индексу)
    let five_hundred = x.0;
    let six_point_four = x.1;
    let one = x.2;

    println!("Элементы: {}, {}, {}", five_hundred, six_point_four, one);

    // Деструктуризация кортежа
    let (a, b, c) = x;
    println!("Деструктуризация: a = {}, b = {}, c = {}", a, b, c);
}
```


**Доступ к элементам и деструктуризация**
- Доступ к конкретным элементам кортежа осуществляется через «точку» и его индекс: `x.0`, `x.1`, `x.2`.
- Индексация начинается с нуля.
- Кортеж также можно разобрать на отдельные переменные с помощью деструктуризации: `let (a, b, c) = x;`.


#### Шаг 3


```rust
#[allow(unused_variables)]
fn main() {
    // Пример блока кода, вычисляющегося в единичный тип ():
    let x: () = {
        println!("Печать внутри блока кода");
        // Выражение с точкой с запятой в конце возвращает ()
    };

    // Функция, не возвращающая значения, возвращает ()
    let y: () = implicit_unit();

    println!("x: {:?}", x);
    println!("y: {:?}", y);
}

// Функция неявно возвращает ()
fn implicit_unit() {
    // Нет выражения возврата
}
```


**Единичный тип (Unit-type)**
- Пустой кортеж `()` представляет собой единичный тип.
- Блоки кода, заканчивающиеся точкой с запятой `;`, вычисляются в `()`.
- Функции, не имеющие явного возвращаемого типа, неявно возвращают `()`.

<h2 class="relative group">Крайний случай: Пустой кортеж (Unit-тип)
    <div id="крайний-случай-пустой-кортеж-unit-тип" class="anchor"></div>
    
    <span
        class="absolute top-0 w-6 transition-opacity opacity-0 -start-6 not-prose group-hover:opacity-100 select-none">
        <a class="text-primary-300 dark:text-neutral-700 !no-underline" href="#%d0%ba%d1%80%d0%b0%d0%b9%d0%bd%d0%b8%d0%b9-%d1%81%d0%bb%d1%83%d1%87%d0%b0%d0%b9-%d0%bf%d1%83%d1%81%d1%82%d0%be%d0%b9-%d0%ba%d0%be%d1%80%d1%82%d0%b5%d0%b6-unit-%d1%82%d0%b8%d0%bf" aria-label="Якорь">#</a>
    </span>
    
</h2>
<ul>
<li>Пустой кортеж записывается как <code>()</code>.</li>
<li>Альтернативное название: <strong>«Единичный» тип (unit type)</strong>.</li>
<li><strong>Свойства и поведение:</strong>
<ol>
<li>Функции, у которых явно не указан возвращаемый тип (ничего не возвращают), на самом деле неявно возвращают пустой кортеж <code>()</code>.</li>
<li>Ряд выражений языка вычисляются в пустой кортеж. К ним относятся циклы (например, <code>for</code>), а также блоки кода, завершающиеся выражением с точкой с запятой <code>;</code>.</li>
</ol>
</li>
</ul>
