### 💻 Пример ошибки E0425 (Неразрешенное имя)


#### Шаг 1


```rust
// ?compile_fail
fn main() {
    let message = "Привет, Rust!";
    // Опечатка в имени переменной: messg вместо message
    println!("{}", messg);
}
```


**Ошибка E0425: Использование неизвестного имени**
- Компилятор Rust прерывает сборку, поскольку имя `messg` не объявлено в данной области видимости.
- Обратите внимание на помощь компилятора: он автоматически ищет похожие переменные и предлагает исправить опечатку.


#### Шаг 2


```rust
fn main() {
    let message = "Привет, Rust!";
    // Исправляем опечатку
    println!("{}", message);
}
```


**Исправление опечатки**
- Заменив `messg` на `message`, мы обращаемся к реально существующей и объявленной переменной.
- Теперь компилятор успешно соберёт программу, и в терминале отобразится приветствие.

<p>Другой популярной ошибкой, с которой часто сталкиваются новички, является несоответствие типов (<code>E0308</code>). Rust — язык со строгой статической типизацией. Он не выполняет неявные преобразования за вас (например, он не превратит число с плавающей точкой в целое число автоматически).</p>
<p>Давайте посмотрим на интерактивном слайде, как выглядит эта ошибка и как её исправить:</p>
### 💻 Пример ошибки E0308 (Несоответствие типов)


#### Шаг 1


```rust
// ?compile_fail
fn main() {
    // В Rust строгая типизация. Мы не можем присвоить число с плавающей точкой
    // переменной, которая ожидает целое число без явного приведения.
    let speed: i32 = 12.5; 
    println!("Скорость: {}", speed);
}
```


**Ошибка E0308: Несоответствие типов (Mismatched Types)**
- Мы указали тип `i32` (целое число), но присвоили значение `12.5` (с плавающей точкой).
- Rust не выполняет неявных преобразований типов, чтобы уберечь вас от потери данных или точности.


#### Шаг 2


```rust
fn main() {
    // Способ 1: Изменить тип переменной на соответствующий
    let speed_float: f64 = 12.5;
    
    // Способ 2: Явное приведение типов с помощью оператора `as`
    let speed_int: i32 = 12.5 as i32;

    println!("Дробная скорость: {}, Целая скорость: {}", speed_float, speed_int);
}
```


**Решение несоответствия типов**
- Либо меняем тип на `f64` или `f32` для сохранения точности.
- Либо явно приводим значение к `i32` с помощью `as i32` (при этом дробная часть будет отброшена).

### 📝 Разбираемся с ошибками в Rust

**1. Какой командой в терминале можно получить подробную документацию по конкретному коду ошибки?**

- [ ] rustup doc E0425
- [x] rustc --explain E0425
- [ ] cargo explain E0425
- [ ] rustc --help E0425

> 💡 *Команда `rustc --explain <код_ошибки>` выводит подробное описание ошибки с примерами некорректного кода и способами его исправления прямо в терминал.*


**2. Что означает ошибка E0425 в компиляторе Rust?**

- [ ] Несоответствие типов данных (Mismatched Types)
- [x] Использование необъявленного или неразрешенного имени (переменной, функции и др.)
- [ ] Нарушение правил владения (Use of moved value)
- [ ] Выход за границы массива при доступе по индексу

> 💡 *Ошибка E0425 сигнализирует о том, что вы попытались использовать идентификатор (переменную, константу или функцию), который компилятор не может найти в текущей области видимости (например, из-за опечатки).*


**3. Как Rust отнесется к попытке неявного приведения дробного числа к целому (например, let x: i32 = 5.5)?**

- [ ] Автоматически округлит значение до 5
- [ ] Автоматически округлит по правилам математики до 6
- [x] Выдаст ошибку компиляции E0308 (Mismatched Types)
- [ ] Скомпилирует код, но программа упадет с паникой во время работы

> 💡 *Rust обладает строгой статической типизацией и не выполняет неявных преобразований типов во избежание непреднамеренной потери точности. Такая попытка вызовет ошибку E0308.*


**4. Какой первый шаг рекомендуется сделать при возникновении ошибки компиляции перед поиском ответа в интернете?**

- [ ] Переустановить компилятор Rust
- [x] Внимательно прочитать сообщение об ошибке и использовать rustc --explain
- [ ] Сразу скопировать текст в ChatGPT
- [ ] Заменить все проблемные типы на тип `String`

> 💡 *Компилятор Rust предоставляет очень подробные и понятные сообщения об ошибках, часто указывая точное место и способ исправления, а утилита `--explain` дает развернутый разбор. Это самый надежный источник информации.*


**5. Где находится официальный онлайн-каталог всех кодов ошибок компилятора Rust?**

- [x] На сайте doc.rust-lang.org в разделе Error Index
- [ ] В репозитории GitHub в файле README.md
- [ ] На сайте StackOverflow
- [ ] В панели управления Rustup

> 💡 *Раздел Error Index на doc.rust-lang.org содержит полную интерактивную базу данных по всем кодам ошибок Rust с возможностью запуска примеров кода прямо в браузере.*
