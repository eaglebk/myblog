<p>Если вы тоже захотите поэксперементировать, то вот пара советов:</p>
<ul>
<li>используйте <code>()</code> чтобы создать хор <code>спасибо Илье за лайфхак!</code></li>
<li>чтобы нейронка правильно ставила ударения выдел<code>Я</code>йте ударную б<code>У</code>кву</li>
<li>используйте теги чтобы разнообразить звучание, которые иногда помогают получить интересные эффекты: <code>[Epic Intro]  [Instrumental] [Intro] [Verse] [Drop] [Bridge] [Chorus] [Breakdown] [Epic Outro] [Fade Out and End]</code></li>
<li>не бойтесь смешивать и эксперементировать с жанрами <a href="https://www.suno.wiki/faq/style-and-lyrics/styles-and-genres/"  target="_blank" rel="noreferrer">ссылка на список стилей и жанров</a></li>
<li>старайтесь добавить в текст рифму и не используйте большое кол-во строк для припевов</li>
<li>не забывайте добавлять паузы</li>
<li>иногда полезно искажать буквы чтобы добиться правильного произношения</li>
</ul>
