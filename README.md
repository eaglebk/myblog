## 🇷🇺 О репозитории

Этот репозиторий содержит скомпилированную версию инженерного блога **[eagle2000.space](https://eagle2000.space)** от разработчика Константина (**@eaglebk**). Блог посвящен системному программированию на Rust, микроконтроллерам, мобильной разработке (Flutter/Dart) и фотографии.

🌐 **Сайт:** [https://eagle2000.space](https://eagle2000.space)

* 📱 **[TIL & Инженерия](https://eagle2000.space/til/)** — короткие практические заметки по Flutter, Dart, Swift и базам данных.
* 📚 **[Книжная полка](https://eagle2000.space/books/)** — проверенные книги по архитектуре и системному дизайну.
* 📸 **[Фотография и композиция](https://eagle2000.space/photography/)** — статьи с интерактивными симуляторами кадрирования и [авторская галерея снимков с EXIF-данными](https://eagle2000.space/my-gallery/).

## 🇬🇧 About the Repository

This repository hosts the compiled production build of the engineering blog **[eagle2000.space](https://eagle2000.space)** by Konstantin (**@eaglebk**), focusing on Rust systems programming, embedded devices, mobile engineering (Flutter/Dart), and visual arts.

🌐 **Website:** [https://eagle2000.space](https://eagle2000.space)

### 📌 Key Topics:
* 🦀 **[Rust Series](https://eagle2000.space/en/rust/)** — a practical guide of 60+ articles featuring runnable in-browser code slides:
  * [Core Language Syntax](https://eagle2000.space/en/rust/start-rust/)
  * [Memory Management (RAII, Box, Deref)](https://eagle2000.space/en/rust/rust-raii-box-deref/)
  * [Trait Objects & Dynamic Polymorphism](https://eagle2000.space/en/rust/rust-dyn-traits/)
  * [Tokio Concurrency & Channels](https://eagle2000.space/en/rust/rust-tokio-channels/)
  * [Embedded Rust: Wireless Web Thermometer on ESP32](https://eagle2000.space/en/rust/esp32-rust-thermometer/)
* 📱 **[TIL & Mobile Tech](https://eagle2000.space/en/til/)** — concise engineering notes on Flutter, Dart, Swift, and backend tooling.
* 📚 **[Bookshelf](https://eagle2000.space/en/books/)** — curated reads on software architecture and systems design.
* 📸 **[Photography & Composition](https://eagle2000.space/en/photography/)** — articles with interactive framing trainers and an [EXIF-enabled photo gallery](https://eagle2000.space/en/my-gallery/).
